## Recursão
Uma função pode chamar outra em C. o conceito da recursão envolve casos em que uma função chama ela mesma.
Promovem simplicidade e legibilidade no código, mas em sacrifício de eficiência, especialmente em casos como usar recursividade para calcular fibonacci. (ver códigos relacionados)

## Busca
A ação de buscar um elemento em um conjunto de dados, visa responder se certo valor de input está ou não em dito conjunto de dados.
**_chave:_** _o que estamos buscando?_
+ palavra
+ valor
+ campo de struct
+ etc...
_Aonde estamos buscando?_
+ Array
+ Lista
+ Árvore
+ etc...
Outras coisas para considerar: _Os dados estão ordenados? há possíveis duplicatas?_

Tipos de busca: Linear (comum) e Binária
### Busca Binária
Utiliza o conceito de dividir para conquistar, só funciona em arrays ou quaisquer estruturas quando ordenadas (ver códigos relacionados)
